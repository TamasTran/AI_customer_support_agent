# Order Cancellation Policy

An order can be cancelled only while it is still in `pending` status —
meaning payment has not yet been captured and the order has not shipped.

Once an order moves to `paid`, `shipped`, or `delivered`, it can no longer
be cancelled. At that point the customer should be offered a refund instead
(see the Refund Policy), not a cancellation.

Cancellation is immediate and irreversible: once cancelled, the same order
cannot be reinstated. The customer would need to place a new order if they
change their mind again.
